# Параметры анализа

Проекции SFS выбираются автоматически после QC и удаления родственников. Рекомендуемый режим:

```yaml
projection_selection:
  mode: auto
  min_fraction_of_max_sites: 0.99
```

Для каждой популяции берётся минимальная проекция, сохраняющая не менее 99% максимального числа сегрегирующих сайтов. Проверить результат можно в `results/sfs/selected_projections.tsv`. Режим `max` выбирает абсолютный максимум, а `manual` позволяет задать проекции явно; менять режим обычно не требуется.

В `config/config.yaml`:

- `gadma.selection_repeats` — число независимых запусков каждой модели;
- `gadma.refinement_repeats` — число запусков для выбранной модели;
- `gadma.processes` — параллельность внутри GADMA;
- `qc.king_cutoff` — порог удаления родственников;
- `gadma.bounds` — границы параметров демографической модели.

Число ядер задаётся последним аргументом команды, например `bash run_docker.sh select 16`. Оно должно быть не меньше `gadma.processes`. Увеличение repeats повышает устойчивость результата, но почти пропорционально увеличивает время расчёта.

Если оптимум достигает границы из `gadma.bounds`, границу нужно расширить и заново сравнить все модели. Встроенного лимита времени нет; внешний walltime должен иметь запас.

`mutation_rate`, `generation_time_years` и `sequence_length` из `config/scaling_scenarios.yaml` используются только для перевода результата в годы и абсолютные размеры после оптимизации. Они не меняют SFS, likelihood или AIC. `sequence_length` — число callable нейтральных аутосомных оснований, а не число SNP.
