# GADMA2: демографические гипотезы A–G–M

Воспроизводимый конвейер для сравнения четырёх гипотез родства ашкеназских (A), грузинских (G) и горских (M) евреев по данным WGS/VCF/BCF.

## Гипотезы

- `S0`: одновременное разделение трёх ветвей (политомия; нулевая внутренняя ветвь).
- `T1 A|(G,M)`: ашкеназы отделяются первыми.
- `T2 G|(A,M)`: грузинские евреи отделяются первыми.
- `T3 M|(A,G)`: горские евреи отделяются первыми.

Все модели допускают симметричный обмен генами между каждой парой современных популяций. Последовательные модели также допускают обмен между первой отделившейся ветвью и предковой ветвью двух остальных популяций. `S0` вложена в последовательные модели при длине внутренней ветви, стремящейся к нулю.

## Что делает pipeline

1. Строго проверяет уникальность ID и наличие каждого образца из `metadata/samples.csv` в BCF.
2. Автоматически распознаёт `1`–`22` или `chr1`–`chr22` и оставляет только аутосомные двухаллельные SNP; фильтрует пропуски и MAC. Если в BCF есть только `GT`, фильтры по GQ/DP неприменимы.
3. Делает LD-pruning и выбирает неродственных образцов алгоритмом KING (`kinship > 0.0884`, примерно до второй степени родства).
4. Строит folded 3D-SFS через easySFS. Folded выбран намеренно: без надёжной анцестральной аллели разворачивать SFS нельзя.
5. Запускает четыре custom-модели GADMA2 (`moments`) с повторными оптимизациями.

## Запуск на лабораторном компьютере

### Вариант Docker (рекомендуется)

Нужно установить только Docker и Git. После клонирования проекта и копирования BCF:

```bash
docker build -t jews-demography:latest .
cp /path/to/jews.bcf raw/jews.bcf
bash run_docker.sh 16
```

Все вычислительные программы устанавливаются внутри образа; результаты появляются в `results/` на хост-компьютере. BCF не включается в образ и монтируется только во время запуска.

### Нативный запуск без Docker

Требуются Linux, Git и Mambaforge/Miniforge. После клонирования:

```bash
git clone <URL-ЭТОГО-РЕПОЗИТОРИЯ>
cd <ПАПКА-РЕПОЗИТОРИЯ>
mamba create -n jews-demography -c conda-forge -c bioconda snakemake-minimal=8 conda
mamba activate jews-demography
mkdir -p raw
cp /path/to/jews.bcf raw/jews.bcf
bash run.sh 16
```

BCF намеренно не хранится в Git. Исходный CSV сокращён до трёх анализируемых популяций; остальные группы и неизвестные метки не смешиваются с анализом.

## Перед полным запуском

Сначала выполните до preview:

```bash
snakemake -s workflow/Snakefile --use-conda --cores 8 results/sfs/preview.txt
cat results/sfs/preview.txt
```

Проверьте предложенные проекции easySFS и при необходимости измените `projections` в `config/config.yaml`. Текущие значения `[70, 20, 70]` выбраны по preview для 41/13/48 неродственных образцов, однако preview нужно проверить заново после изменения набора вариантов.

Для перевода оценок в годы и абсолютные размеры задайте в конфиге обоснованные `mutation_rate`, `sequence_length` (число реально callable нейтральных аутосомных оснований после масок, а не число SNP и не полный размер референса) и `generation_time`. Эти величины нужны для масштабирования через theta и не меняют оптимизацию likelihood в генетических единицах, поэтому их можно применить к сохранённой лучшей модели после завершения GADMA. До этого результаты остаются в генетических единицах.

После фильтрации файл `results/qc/autosomes.variant_counts.tsv` должен содержать только 22 аутосомы. Его необходимо проверить до интерпретации SFS и результатов GADMA.

## Сравнение моделей

Основные результаты находятся в `results/gadma/{S0,T1,T2,T3}/`. Сравнивайте максимальный log-likelihood и AIC (`2k - 2logL`); число свободных параметров: 7 для S0 и 9 для T1–T3. Для связанных WGS-SNP обычный AIC формально оптимистичен. Для публикационного вывода добавьте блочный bootstrap по независимым геномным блокам и используйте CLAIC, как в model-selection tutorial воркшопа GADMA.

## Важные ограничения

- Фильтр глубины 8–60 — стартовая настройка, а не универсальная истина; проверьте распределение DP.
- HWE-фильтр намеренно не применён до разделения по популяциям: общий HWE-тест на структурированной выборке создаёт эффект Валунда.
- KING выбирает максимально большую неродственную подвыборку, но список удалённых образцов следует проверить вместе с метаданными качества/покрытия.
- Половые хромосомы исключаются автоматически. Для WGS всё равно желательно применить callable BED-маску, исключающую повторы, low-complexity и плохо маппируемые участки; без неё нельзя корректно задать `sequence_length`.

Основа: [воркшопы GADMA](https://github.com/noscode/GADMA_workshops), включая easySFS, custom models и сравнение AIC/CLAIC.

## Подготовка метаданных

В `metadata/samples.csv` оставлены только три группы, заданные гипотезами: Ashkenazi, Georgian и Mountain Jews (41/14/48 образцов в исходной таблице). Bukharan, Kurdistan, No Tag и Unknown исключены до анализа и не должны попадать в SFS.

Перед публикацией результатов проверьте, что согласие на использование геномных данных допускает передачу производных SFS и метаданных в открытый репозиторий. Сам BCF намеренно не включён в Git.
